**Neon Coast Cover Studio** — turn any photo and a caption into original poster-style cover art, offline in the browser. Multi-panel layouts (Hero + 3, Diagonal Cut, Triple Strip, Four Square, Full Bleed, Tilted Snaps), per-panel crop/pan/zoom, six grades (Vice Sunset, Neon Night, Golden Hour, Palm Teal, Noir Mono, Original), bold Anton lettering with a Pacifico script subtitle, and one-click PNG export at 1080×1080, 1080×1350 and 1920×1080. No photo ever leaves your device.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — drop in your photos, pick a layout and grade, write your title, export.
