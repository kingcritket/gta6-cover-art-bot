**Neon Coast Cover Studio** is an offline cover-art maker: drop in a photo, add a caption, and get bold GTA-poster-style cover art back as a PNG. It offers six multi-panel layouts (hero, diagonal cut, triple strip, four-square grid, full bleed, and tilted snapshots) with per-panel crop, pan, and zoom, six colour grades from Vice Sunset to Noir Mono, and poster lettering set in Anton with a Pacifico script subtitle. Finished covers export as PNG at three sizes — 1080 × 1080, 1080 × 1350, and 1920 × 1080 — and the whole studio runs fully offline in the browser: your photos never leave your device.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.
